# Trade Resource Library Update

This build connects the generated trade SEO pages to the visible website design.

## New public page

- `/trade-resources` — searchable preparation library for every trade.

## Where users can now find the pages

- Main navigation: **Resources**
- Homepage: **Find the exact page you need for your trade**
- Every trade hub: sticky resource navigation and complete preparation library
- Every mock test, Level page, study guide, exam-preparation page, certification page and passing-score page: sticky trade resource navigation
- Footer: **Preparation Library**

## Tested locally

The following routes returned HTTP 200 during testing:

- `/trade-resources`
- `/trades/carpentry`
- `/trades/carpentry/mock-test`

Payment, login, database, account and access-control logic were not modified.
