# Image setup for Red Seal Practice

The project is already connected to these image paths. Add your image files using the exact names below.

## Homepage hero
- `public/images/home/home-hero.jpg`
- Recommended: 1600 × 1100 px, JPG/WebP-quality photo, subject positioned toward the centre/right.

## FAQ support image
- `public/images/ui/faq-support.jpg`
- Recommended: 900 × 700 px. Use a helpful tradesperson, support representative, study desk, or exam-preparation image.

## Social sharing image
- `public/images/social/og-image.jpg`
- Recommended: 1200 × 630 px.

## Article images
Use 1600 × 900 px (16:9), JPG, compressed for web.

- `public/images/articles/red-seal-exam-preparation-guide.jpg`
- `public/images/articles/why-skilled-trades-are-a-strong-career-choice.jpg`
- `public/images/articles/workplace-safety-skilled-trades.jpg`

## Optional trade images
You can later place trade images in `public/images/trades/` using the trade slug, for example:
- `construction-electrician.jpg`
- `plumber.jpg`
- `carpentry.jpg`
- `automotive-technician.jpg`

Do not rename the files unless you also update their paths in the code.
